## 待确认规则

| 事项             | 当前已确认                   | 尚需决定                                                                                             |
| ---------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------- |
| 折扣范围         | 手动输入优惠金额             | 每个维修项目单独折扣，还是整单统一折扣；是否允许二者同时存在                                         |
| 折后价存储       | 不写入报价表，不覆盖原报价   | 是否也不持久化维修单折后金额；建议保留本单原价及折扣金额，动态计算折后价，以支持历史结算，待用户确认 |
| IVA              | 末尾展示加上 IVA 的参考价    | 税率来源、原报价是否未税、按折后金额还是其他基数计算、分项或总额舍入、是否仅供参考且不影响应收余额   |
| 报价口径         | 接单时逐项报价               | 报价为零时的业务处理；历史价格采用“最近报价”的具体范围和选择规则                                     |
| 自动新增报价权限 | 缺失报价时手填并保存到报价表 | 当前 MVP 仅店主维护报价表；员工开单自动保存新报价如何授权，不能在实施时静默扩大权限                  |
| 字典维护         | 新故障保存后可复用           | 谁能改名、停用和合并；重复故障、品牌、型号的标准化和去重方式                                         |
| 报价匹配         | 优先预设报价，历史报价辅助   | 现有精确型号 → 品牌系列 → 通用项目的规则如何与历史报价衔接                                           |
| 黄色主题         | 整体以黄色为基调             | 具体色值、背景与按钮层级在实施时出稿检查，错误／成功状态仍需易于辨识                                 |

## 常见故障预设候选

| 适用类型         | 候选项                                                                                                                                               |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 通用             | 无法开机、无法充电／供电异常、续航差、自动关机／重启、运行慢／卡顿、过热、进液、跌落损坏、故障待检测、其他                                           |
| 手机、平板       | 屏幕破裂、黑屏／显示异常、触摸失灵、后盖损坏、摄像头异常、听筒异常、扬声器异常、麦克风异常、按键失灵、无法识别 SIM 卡、移动网络异常、Wi-Fi／蓝牙异常 |
| 笔记本、台式电脑 | 无法进入系统、蓝屏／死机、屏幕／显示异常、键盘异常、触控板／鼠标异常、接口异常、硬盘／存储异常、风扇异响、网络异常、声音异常                         |
| 游戏机           | 无画面输出、手柄连接异常、摇杆漂移、按键失灵、无法读取游戏、存储异常、联网异常、风扇异响                                                             |

不适用的通用项应按设备隐藏，例如无电池台式机不显示“续航差”。清灰、系统安装、数据迁移属于维修／服务项目，不混入故障列表。预设数量和最终名称在实施前确定；少见故障支持手填并复用的机制已确认。
