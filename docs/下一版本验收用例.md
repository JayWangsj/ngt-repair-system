# 下一版本验收用例

本文随 2026-09-21 需求整理新增。以下是下一版功能的测试设计，尚未执行，不代表功能已实现。待确认规则以 [下个版本计划](下个版本计划.md) 为准，确认后补充精确断言和自动化测试。

| 编号 | 场景                             | 预期                                                                                               |
| ---- | -------------------------------- | -------------------------------------------------------------------------------------------------- |
| N01  | 姓名或电话缺失时创建工单         | 阻止提交并定位缺失字段；两者齐全可继续                                                             |
| N02  | 搜索老客户、选择历史设备         | 正确带出客户及设备信息，切换客户不残留上一客户设备                                                 |
| N03  | 开单页新增客户                   | 无需离开开单页，保存成功后关联正确客户                                                             |
| N04  | 切换设备类型、品牌               | 下游选项联动，清除不兼容型号，支持搜索和新增                                                       |
| N05  | 多选故障并手填少见故障           | 保存后重新开单可选新故障；本单备注不进入公共选项                                                   |
| N06  | 保存失败或重复新增故障           | 不产生孤立或重复选项；规则确认后增加并发及标准化断言                                               |
| N07  | 报价表命中或缺失                 | 命中即预设历史报价；缺失时手填正常原价并加入报价表，不引入另一套历史建议价                         |
| N08  | 多维修项目报价                   | 汇总准确，不同型号或配件规格不串价；金额按整数分计算                                               |
| N09  | 修改正常报价或仅添加折扣         | 正常报价更新匹配报价表；单项／整单优惠、折后价及 IVA 不更新报价表；既有工单不被追溯修改            |
| N10  | 单项与整单优惠同时存在           | 按整单汇总折扣，避免重复扣减；采用计划中的待核对算例补充精确金额断言                               |
| N11  | 关闭折扣、负数、超原价及小数金额 | 不残留隐藏折扣；非法金额拒绝；合计优惠不得超过原价总额                                             |
| N12  | 固定 22% IVA 及计入应收选择      | 原价未税，末尾展示含税价；选择后影响应收和余额，不选仅参考；舍入与默认值确定后补齐断言             |
| N13  | 接单时未付款、部分付款或付清     | 均能按已确认报价流程处理，余额及付款流水准确                                                       |
| N14  | 创建后尝试新增预付款             | 界面和服务端均拒绝；允许正常后补维修款，保留防重复和防超收校验                                     |
| N15  | 单人免登录使用                   | 无需账号或登录即可进入业务、开单及维护报价；不显示员工管理和角色限制；仍验证业务输入并保留历史记录 |
| N16  | 黄色主题的桌面和移动端           | 主按钮、选中状态统一；文字可读，键盘焦点和错误状态清楚，无横向溢出                                 |
| N17  | 最简开单流程                     | 同页完成必需信息；无接单渠道、随机配件、负责人必填阻塞；打印或通知不阻塞保存                       |

## 新增结算回归场景

- N18：保存后重新打开维修单，本单原价、折扣及 IVA 选择可还原，余额与付款流水一致；报价表仍为正常原价。
- N19：报价表正常价格后续变更，旧单原价、优惠、IVA 选择和已收款不被改写。
- N20：已收款后修改折扣或 IVA 选择，按确认后的规则处理应收小于已收款的情况，不能静默产生负余额或改写流水。
- N21：已有账号关联的工单在取消登录后仍可查看和操作，历史业务数据不丢失。
