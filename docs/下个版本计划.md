## 待确认规则

折扣共存、正常报价更新报价表、22% IVA、原价未税、IVA 可选计入应收及单人免登录已确认，统一移入 CHANGELOG；不再保留过时的员工权限、两套历史报价或税率待定事项。

| 事项           | 当前已确认                               | 尚需决定或核对                                                                                         |
| -------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 折扣计算细节   | 单项和整单折扣可同时存在，按整单计算     | 暂按两者合并后从原价总额扣减一次解释；下方算例需核对                                                   |
| IVA 计算细节   | 固定 22%，原报价未税，可选择是否计入应收 | 暂按整单折后未税价计算；总额舍入方式、选择框默认状态待定                                               |
| 已收款后的调价 | 保留报价和付款记录                       | 折扣或 IVA 选择变化使应收低于已收款时如何处理，不能静默产生负余额或修改付款记录                        |
| 报价口径       | 报价表价格即历史报价，正常报价更新报价表 | 报价为零时的业务处理；同单同型号同项目出现不同正常报价时的更新规则                                     |
| 字典维护       | 唯一使用者可维护，新故障保存后可复用     | 重复故障、品牌、型号的标准化和去重方式，改名／停用／合并的具体操作                                     |
| 报价匹配       | 从报价表预设价格                         | 核对现有精确型号 → 品牌系列 → 通用项目规则；使用通用预设后修改具体型号价格时，新增精确项还是更新通用项 |
| 黄色主题       | 整体以黄色为基调                         | 具体色值、背景与按钮层级在实施时出稿检查，错误／成功状态仍需易于辨识                                   |

### 计算解释示例（待核对，不是已实现结果）

- 两个项目未税正常报价分别为 €100 和 €50，报价表分别记录 €100 和 €50。
- 单项优惠合计 €10，另有整单优惠 €5；暂按整单总优惠 €15 计算，整单折后未税价为 €135。
- 暂按折后未税价计算 IVA：€135 × 22% = €29.70；含 IVA 金额为 €164.70。
- 已收款 €20 时，不选“IVA 计入应收”的余额为 €115；选中时为 €144.70。
- 上述折后金额与含税金额都不写回报价表；单项和整单优惠不重复扣减。
