# 意大利手机维修店管理系统 MVP 产品设计文档

## 1. 产品定位

面向意大利本地手机维修小店的日常经营管理工具。第一版聚焦“快速接单、清楚报价、可追踪维修、顺利收款”四件事，减少纸质登记、口头报价和工单遗漏。

## 2. MVP 目标

- 店员可在约两分钟内完成一张维修工单的登记。
- 根据设备型号和维修项目，快速得到可调整的建议报价。
- 店主可随时了解维修进度、待取设备和当日收款。
- 为客户留存维修和报价记录，降低沟通与售后争议。

## 3. 目标用户

| 用户 | 主要诉求 |
| --- | --- |
| 店主 | 掌握营业、工单进度和未结款；维护报价标准。 |
| 店员/维修员 | 快速登记、报价、更新维修状态和交付。 |
| 客户 | 知道维修内容、价格、预计完成时间和取机状态。 |

## 4. 核心业务流程

```text
客户到店
  → 登记客户与设备
  → 选择维修项目并取得建议报价
  → 确认报价/记录客户确认
  → 检测与维修，更新工单状态
  → 收取尾款并交付设备
  → 留存客户及维修历史
```

## 5. MVP 主要功能

### 5.1 工单管理

- 新建、编辑、查询工单。
- 登记客户姓名、电话、设备品牌与型号、IMEI（可选）、故障描述、设备外观状况、随设备交付的附件。
- 记录预计交付日期、备注，以及订金和尾款。
- 支持照片留档和基础免责声明作为后续增强功能。

### 5.2 维修状态与看板

工单状态统一为：`已接收`、`检测中`、`维修中`、`缺配件`、`待取机`、`返修中`、`已交付`、`已退款`、`已取消`。

- 使用列表或看板查看各状态的工单。
- 突出显示待取机和逾期工单。
- 每次状态变更保留操作时间和操作人。

### 5.3 建议报价与报价表

报价表由店主维护，规则包含：品牌、设备型号、维修项目、建议报价（欧元）、成本价（可选）、预计工时、启用状态和备注。

- 在工单中选择“型号 + 维修项目”后，自动匹配建议报价。
- 支持一张工单含多个维修项目，自动汇总建议总价。
- 店员可修改最终报价；保存系统建议价、最终报价及调整原因。
- 无匹配报价时允许手工录入，并可一键保存为新的报价规则。
- 匹配优先级：精确型号 + 项目 → 品牌/系列 + 项目 → 通用项目。

### 5.4 客户与设备档案

- 根据电话号码查询或新建客户。
- 一个客户可管理多台设备。
- 展示客户的历史工单、维修项目、报价和付款记录。

### 5.5 收款与交付

- 支持订金、尾款和完整付款记录。
- 记录支付方式：现金、银行卡、转账等。
- 交付时将工单标记为已完成，记录取机时间和取机人。
- 输出或发送简单收据为后续增强功能。

### 5.6 经营概览

首版仅提供基础数据：

- 当日收款金额与工单数量。
- 各维修状态的工单数量。
- 待取机、逾期和未结款工单。
- 常见维修项目和设备型号（可选）。

## 6. 主要页面

| 页面 | 作用 |
| --- | --- |
| 首页/维修看板 | 查看待处理、维修中、待取机及关键提醒。 |
| 工单列表 | 搜索、筛选和进入工单。 |
| 新建/编辑工单 | 登记客户、设备、维修项目、报价和付款信息。 |
| 工单详情 | 查看完整记录、修改状态、追加项目与确认交付。 |
| 客户详情 | 查看客户资料、设备和历史维修。 |
| 报价管理 | 维护可编辑的型号与维修项目报价表。 |
| 经营概览 | 查看每日基础经营数据。 |

## 7. 本地化与合规方向

- 金额使用欧元，日期和界面优先适配意大利本地习惯，并预留意大利语界面。
- 收集最少必要的客户信息，并提供基础隐私同意记录，以支持 GDPR 要求。
- 预留 `codice fiscale`、`partita IVA` 和电子发票相关字段；正式税务/电子发票对接不纳入 MVP。
- 预留维修前风险说明、设备外观照片和客户签字能力，优先级低于核心工单流程。

## 8. MVP 范围外功能

以下功能在验证核心流程后再考虑：库存与采购、多门店管理、员工排班与权限细分、线上预约/商城、自动 WhatsApp 或短信通知、复杂财务报表、完整电子发票与税务平台集成。

## 9. 成功标准

- 店员能独立完成“登记 → 报价 → 状态更新 → 收款交付”全流程。
- 每张工单均可追溯客户、设备、维修项目、报价和付款。
- 店主打开首页即可识别当日工作重点和待跟进工单。
